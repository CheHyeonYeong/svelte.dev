축하합니다! 이 튜토리얼을 끝까지 마쳤다면 이제 스스로를 Svelte와 SvelteKit 전문가라고 여겨도 좋습니다.

[Svelte CLI](https://www.npmjs.com/package/sv)로 여러분의 컴퓨터에서 직접 앱을 만들기 시작할 수 있습니다:

```bash
npx sv create
```

Svelte와 SvelteKit은 계속 발전할 것이고, 이 튜토리얼도 마찬가지입니다. 업데이트가 있는지 가끔 들러 확인해 보세요.

Svelte 세계의 소식을 계속 접하려면 [svelte.dev/chat](/chat)에서 Discord 서버에 참여하고 BlueSky에서 [Svelte Society](https://bsky.app/profile/sveltesociety.dev)를 팔로우하세요. 여러분을 Svelte 커뮤니티에 맞이하게 되어 정말 기쁩니다!
