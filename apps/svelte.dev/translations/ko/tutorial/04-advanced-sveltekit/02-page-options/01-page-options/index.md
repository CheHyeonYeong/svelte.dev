title: 기초
---

[데이터 불러오기](/tutorial/kit/page-data) 장에서 `+page.js`, `+page.server.js`, `+layout.js`, `+layout.server.js` 파일에서 `load` 함수를 export하는 방법을 살펴봤습니다. 이 모듈들에서는 여러 가지 **페이지 옵션**도 export할 수 있습니다:

- `ssr` — 페이지를 서버에서 렌더링할지 여부
- `csr` — SvelteKit 클라이언트를 불러올지 여부
- `prerender` — 요청마다 렌더링하는 대신 빌드 시점에 페이지를 프리렌더링할지 여부
- `trailingSlash` — URL의 후행 슬래시를 제거할지, 추가할지, 무시할지

이어지는 연습에서 하나씩 차례대로 알아보겠습니다.

페이지 옵션은 개별 페이지(`+page.js`나 `+page.server.js`에서 export한 경우)나 여러 페이지 묶음(`+layout.js`나 `+layout.server.js`에서 export한 경우)에 적용할 수 있습니다. 앱 전체에 옵션을 정의하려면 루트 레이아웃에서 export하세요. 하위 레이아웃과 페이지는 부모 레이아웃에서 설정한 값을 재정의하므로, 예를 들어 앱 전체에 프리렌더링을 켜 두고 동적으로 렌더링해야 하는 페이지에서만 끌 수 있습니다.

앱의 영역마다 이 옵션들을 자유롭게 조합할 수 있습니다. 마케팅 페이지는 프리렌더링하고, 데이터 기반 페이지는 서버에서 동적으로 렌더링하고, 관리자 페이지는 클라이언트에서 렌더링하는 SPA로 다룰 수 있습니다. 덕분에 SvelteKit은 매우 다재다능합니다.
