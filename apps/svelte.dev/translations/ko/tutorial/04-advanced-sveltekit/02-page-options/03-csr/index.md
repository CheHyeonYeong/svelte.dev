---
title: csr
---

클라이언트 사이드 렌더링은 페이지를 상호작용할 수 있게 만드는 것으로(이 앱에서 버튼을 클릭하면 카운터가 올라가는 것처럼), SvelteKit이 내비게이션할 때 전체 페이지를 새로고침하지 않고 페이지를 업데이트할 수 있게 해 줍니다.

`ssr`과 마찬가지로 클라이언트 사이드 렌더링도 완전히 끌 수 있습니다:

```js
/// file: src/routes/+page.server.js
export const csr = false;
```

이렇게 하면 클라이언트에 JavaScript가 전혀 전송되지 않지만, 컴포넌트도 더 이상 상호작용하지 않습니다. 어떤 이유로든 JavaScript를 사용할 수 없는 사람들도 애플리케이션을 쓸 수 있는지 확인할 때 유용한 방법입니다.
