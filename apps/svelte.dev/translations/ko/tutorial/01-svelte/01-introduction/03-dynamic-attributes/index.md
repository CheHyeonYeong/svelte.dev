---
title: 동적 속성
---

중괄호로 텍스트를 제어할 수 있는 것처럼, 요소의 속성도 제어할 수 있습니다.

이미지에 `src`가 없네요. 하나 추가해 봅시다:

```svelte
/// file: App.svelte
<img +++src={src}+++ />
```

훨씬 낫습니다. 그런데 에디터에서 `<img>` 위에 마우스를 올려 보면 Svelte가 경고를 보여 줍니다:

```
`<img>` element should have an alt attribute
```

웹 앱을 만들 때는 시각이나 운동 능력에 장애가 있는 사람, 고성능 하드웨어나 좋은 인터넷 연결이 없는 사람 등을 포함해 가능한 한 많은 사용자가 *접근*할 수 있도록 하는 것이 중요합니다. 접근성(줄여서 a11y)을 제대로 챙기기는 쉽지 않지만, 접근성이 떨어지는 마크업을 작성하면 Svelte가 경고해서 도와줍니다.

이 경우에는 스크린 리더를 사용하는 사람이나, 인터넷이 느리거나 불안정해 이미지를 내려받지 못하는 사람을 위해 이미지를 설명하는 `alt` 속성이 빠져 있습니다. 하나 추가해 봅시다:

```svelte
/// file: App.svelte
<img src={src} +++alt="A man dances."+++ />
```

속성 *안*에서도 중괄호를 쓸 수 있습니다. `"{name} dances."`로 바꿔 보세요. `<script>` 블록에 `name` 변수를 선언하는 것도 잊지 마세요.

## 단축 속성 <!-- Shorthand attributes -->

`src={src}`처럼 속성의 이름과 값이 같은 경우는 드물지 않습니다. Svelte는 이런 경우를 위한 편리한 단축 문법을 제공합니다:

```svelte
/// file: App.svelte
<img +++{src}+++ alt="{name} dances." />
```
