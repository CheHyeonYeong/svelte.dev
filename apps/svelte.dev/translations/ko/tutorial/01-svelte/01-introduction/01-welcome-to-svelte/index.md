Svelte 튜토리얼에 오신 것을 환영합니다! 이 튜토리얼에서는 크기와 상관없이 높은 성능과 작은 용량을 갖춘 웹 애플리케이션을 손쉽게 만드는 데 필요한 모든 것을 배웁니다.

[API 문서](/docs)를 참고하거나 [플레이그라운드](/playground)를 둘러볼 수도 있고, 내 컴퓨터에서 얼른 코드를 짜 보고 싶다면 `npx sv create`로 프로젝트를 만들어 보세요.

## Svelte란? <!-- What is Svelte? -->

Svelte는 웹 애플리케이션을 만드는 도구입니다. 다른 사용자 인터페이스 프레임워크처럼, 마크업과 스타일과 동작을 하나로 묶은 컴포넌트로 앱을 *선언적*으로 만들 수 있습니다.

이 컴포넌트들은 작고 효율적인 JavaScript 모듈로 *컴파일*되어, 기존 UI 프레임워크에 흔히 따라오던 오버헤드를 없앱니다.

앱 전체를 Svelte로 만들 수도 있고(예를 들어 이 튜토리얼에서도 다루는 [SvelteKit](/docs/kit) 같은 애플리케이션 프레임워크를 사용해서), 기존 코드베이스에 조금씩 도입할 수도 있습니다. 어디서나 동작하는 독립 패키지로 컴포넌트를 배포할 수도 있습니다.
