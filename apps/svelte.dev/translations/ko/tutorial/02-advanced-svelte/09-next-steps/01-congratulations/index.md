이제 Svelte 튜토리얼을 마쳤으니 무언가를 만들기 시작할 준비가 되었습니다.

튜토리얼의 다음 두 파트에서는 온갖 형태와 규모의 앱을 만들기 위한 완전한 프레임워크인 SvelteKit을 다룹니다.

정보가 너무 많아 버겁고 아직 SvelteKit 튜토리얼을 진행할 준비가 되지 않았더라도 걱정하지 마세요! SvelteKit을 전부 배우지 않아도 지금까지의 Svelte 지식을 그대로 활용할 수 있습니다. 터미널에서 다음 명령을 실행하고 안내를 따라가세요...

```bash
npx sv create
```

...그리고 `src/routes/+page.svelte`를 수정하기 시작하세요. 준비가 되면 아래 링크를 클릭해 여정을 이어 가세요.
