# 한국어 번역 가이드

`translations/ko/docs/...`의 문서를 번역할 때 지키는 규칙과 용어집입니다.
폴더 구조와 동작 방식은 [README.md](./README.md)를 보세요.

## 파일

- `.generated/` 폴더의 파일은 번역하지 않습니다(사이트에 렌더링되지 않는 동기화용 원본).

- 영어 원문 `content/docs/<경로>.md`를 같은 경로의 `translations/ko/docs/<경로>.md`로 번역합니다.
- frontmatter
  - 첫 줄의 `NOTE: do not edit this file ...`는 지웁니다.
  - `title`만 번역하고, 나머지 키(`tags` 등)는 그대로 둡니다.
  - 제목이 모듈·API 이름이면(`$app/forms`, `@sveltejs/kit`, `#lib`) 번역하지 않습니다.
- 다 쓰면 검사합니다: `node scripts/check-translations.ts <파일>` (apps/svelte.dev에서 실행)

### 튜토리얼

- `content/tutorial/**/index.md`를 `translations/ko/tutorial/**/index.md`로 번역합니다. 연습 문제 코드(`+assets`, `app-a`, `app-b`)는 번역하지 않습니다.
- frontmatter는 `title`만 번역하고 `label`, `scope`, `focus`, `path` 등은 그대로 둡니다.
- 파트 이름: Svelte 기초 / Svelte 심화 / SvelteKit 기초 / SvelteKit 심화. exercise는 "연습 문제"입니다.
- 학습자에게 말하는 글이므로 "~해 보세요"처럼 부드러운 합니다체를 씁니다.

## 그대로 두는 것

번역 문서는 영어와 같은 렌더링 파이프라인(코드 타입 검사, API 링크, 앵커)을 거칩니다. 아래는 **한 글자도 바꾸지 않습니다.**

- **코드 블록** (` ``` ` 안 전부, 주석 포함)
- **인라인 코드** (`` `load` ``, `` `+page.svelte` ``)
- **HTML 줄** (`<div class="ts-block">`, `</div>`, `<blockquote class="since note">` 등). 태그 사이의 문장은 번역합니다.
- **링크 주소** (`[텍스트](주소)`에서 텍스트만 번역)
- **콜아웃 표시** (`> [!NOTE]`, `> [!LEGACY]`, `> [!CAUTION]`). 뒤의 문장은 번역합니다.
- **제목 id**: 번역한 제목에는 뒤에 영어 원문 제목을 주석으로 붙입니다.

  ```markdown
  ## 폼 액션 <!-- Form actions -->

  ### 기본 액션 <!-- Default actions -->
  ```

  - 제목이 API 이름 그대로라면(`## load`, `## applyAction`) 번역하지도, 주석을 붙이지도 않습니다.
  - `####` 이하 제목도 마찬가지입니다.

### 영어로 두는 문장

- API 레퍼런스의 배지 라벨: `<span class="tag">default</span>`, `<span class="tag since">available since</span>`, `<span class="tag deprecated">deprecated</span>`, `<span class="tag">returns</span>`. 라벨 뒤의 설명은 번역합니다.
- 실제로 출력되는 에러 메시지, 다른 서비스의 화면 문구(Vercel의 "Settings", Cloudflare의 "Framework preset" 등)

## 강조

한국어 조사가 바로 붙으면 `_강조_를`은 강조로 렌더링되지 않습니다. 번역에서는 **항상 `*강조*를`처럼 `*`를 씁니다.**
강조가 괄호로 끝나지 않게 두세요: `*진입점*(entry point)` (O), `*진입점(entry point)*이` (X)

## 줄 맞춤

원문과 줄 수를 최대한 맞춥니다. 원문이 바뀌었을 때 `git diff`로 고칠 곳을 바로 찾을 수 있습니다.
원문의 한 줄은 번역에서도 한 줄로 두고, 빈 줄의 위치도 같게 유지합니다.

## 문체

- **합니다체**를 씁니다. 예: "~합니다", "~하세요", "~할 수 있습니다"
- "당신"은 쓰지 않습니다. 주어를 생략하거나 필요하면 "여러분"을 씁니다.
- 직역보다 자연스러운 한국어를 우선하되, 기술적 의미는 정확히 옮깁니다.
- 원문의 농담이나 말장난은 뜻이 통하게 옮기고, 어려우면 담백하게 풀어 씁니다.
- 제품·라이브러리·고유명사는 영어 그대로 씁니다: Svelte, SvelteKit, Vite, TypeScript, Node, Vercel, Netlify, Cloudflare, GitHub 등
- 숫자, 단위, 버전은 원문 표기를 따릅니다.
