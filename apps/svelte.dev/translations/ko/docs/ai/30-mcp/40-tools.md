---
title: 도구
---

MCP 서버는 사용 중인 모델에게 다음 도구를 제공하며, 모델은 세션 중에 이 중 하나 이상을 호출할지 스스로 결정할 수 있습니다:

## list-sections

사용 가능한 모든 문서 섹션의 목록을 제공합니다.

## get-documentation

모델이 요청한 섹션의 전체(그리고 최신) 문서를 [svelte.dev/docs](/docs)에서 직접 가져올 수 있게 합니다.

## svelte-autofixer

정적 분석을 사용해 LLM이 생성한 코드에 대한 제안을 제공합니다. 모든 문제와 제안이 해결될 때까지 모델이 에이전트 루프 안에서 반복해서 호출할 수 있습니다.

## playground-link

생성된 코드로 임시 플레이그라운드 링크를 만듭니다. 생성된 코드가 프로젝트의 파일로 작성되지 않았고 생성된 결과를 빠르게 테스트해 보고 싶을 때 유용합니다. 코드는 URL 자체 외에는 어디에도 저장되지 않습니다(그래서 URL이 꽤 길어지는 경우가 많습니다).
