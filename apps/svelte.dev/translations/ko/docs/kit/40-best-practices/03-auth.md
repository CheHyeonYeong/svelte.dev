---
title: 인증
---

인증(auth)은 인증(authentication)과 인가(authorization)를 함께 이르는 말로, 웹 애플리케이션을 만들 때 흔히 필요한 기능입니다. 인증은 사용자가 제공한 자격 증명을 바탕으로 그 사용자가 본인이 주장하는 사람이 맞는지 확인하는 것입니다. 인가는 그 사용자가 어떤 동작을 할 수 있는지 결정하는 것입니다.

## 세션 vs 토큰 <!-- Sessions vs tokens -->

사용자가 사용자 이름과 비밀번호 같은 자격 증명을 한 번 제공하고 나면, 이후의 요청에서는 자격 증명을 다시 입력하지 않고도 애플리케이션을 쓸 수 있게 해야 합니다. 이후 요청에서 사용자를 인증할 때는 보통 세션 식별자나 JSON Web Token(JWT) 같은 서명된 토큰을 사용합니다.

세션 ID는 대개 데이터베이스에 저장합니다. 즉시 폐기할 수 있지만, 요청마다 데이터베이스를 조회해야 합니다.

반면 JWT는 일반적으로 데이터 저장소와 대조하지 않으므로 즉시 폐기할 수 없습니다. 이 방식의 장점은 지연 시간이 줄고 데이터 저장소의 부하가 줄어든다는 것입니다.

## 통합 지점 <!-- Integration points -->

인증 [쿠키](@sveltejs-kit#Cookies)는 [`handle`](hooks#handle) 훅 안에서 확인할 수 있습니다. 제공된 자격 증명과 일치하는 사용자를 찾으면, 그 사용자 정보를 [`locals`](hooks#handle-locals)에 저장할 수 있습니다.

## 라이브러리 <!-- Libraries -->

[Svelte CLI](/docs/cli)를 사용하면 새 프로젝트를 만들 때 [Better Auth를 설정](/docs/cli/better-auth)하거나 기존 프로젝트에 추가할 수 있습니다.

## 가이드 <!-- Guides -->

인증 시스템을 직접 구현하고 싶다면, [Lucia 인증 가이드](https://lucia-auth.com/)가 SvelteKit 예제와 함께 세션 기반 웹 앱 인증의 레퍼런스를 제공합니다.
