```svelte
<!--- copy: false  --->
{#if expression}...{/if}
```

```svelte
<!--- copy: false  --->
{#if expression}...{:else if expression}...{/if}
```

```svelte
<!--- copy: false  --->
{#if expression}...{:else}...{/if}
```

조건에 따라 렌더링할 내용은 if 블록으로 감쌀 수 있습니다.

```svelte
{#if answer === 42}
	<p>what was the question?</p>
{/if}
```

`{:else if expression}`으로 조건을 추가할 수 있고, 선택적으로 `{:else}` 절로 끝낼 수 있습니다.

```svelte
{#if porridge.temperature > 100}
	<p>too hot!</p>
{:else if 80 > porridge.temperature}
	<p>too cold!</p>
{:else}
	<p>just right!</p>
{/if}
```

(블록이 꼭 요소를 감쌀 필요는 없습니다. 요소 안의 텍스트를 감쌀 수도 있습니다.)
