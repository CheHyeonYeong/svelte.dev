[Storybook](https://storybook.js.org/)은 프론트엔드 컴포넌트 작업 공간입니다.

## 사용법 <!-- Usage -->

```sh
npx sv add storybook
```

## 제공되는 것 <!-- What you get -->

- 다른 모든 애드온에 쓰는 편리한 `sv` CLI에서 `npx storybook init`을 대신 실행
- 기본 설정이 제공되는 [SvelteKit용 Storybook](https://storybook.js.org/docs/get-started/frameworks/sveltekit) 또는 [Svelte & Vite용 Storybook](https://storybook.js.org/docs/get-started/frameworks/svelte-vite). 여러 SvelteKit 모듈을 쉽게 모킹할 수 있고, 링크를 자동으로 처리하는 등 다양한 기능을 제공합니다.
