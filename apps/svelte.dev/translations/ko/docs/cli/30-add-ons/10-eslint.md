[ESLint](https://eslint.org/)는 코드의 문제를 찾아 고쳐 줍니다.

## 사용법 <!-- Usage -->

```sh
npx sv add eslint
```

## 제공되는 것 <!-- What you get -->

- `eslint-plugin-svelte`를 포함한 관련 패키지 설치
- `eslint.config.js` 파일
- 업데이트된 `.vscode/extensions.json`
- TypeScript와 `prettier`를 사용 중이라면 함께 동작하도록 설정
