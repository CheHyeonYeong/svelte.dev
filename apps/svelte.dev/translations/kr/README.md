# 한국어(kr) 번역

Svelte 공식 문서의 한국어 번역입니다.

- 이 폴더는 `apps/svelte.dev/content/`의 구조를 그대로 따릅니다.
  예: `content/docs/svelte/01-introduction/01-overview.md` → `translations/kr/docs/svelte/01-introduction/01-overview.md`
- 영어 원문(`content/`)은 수정하지 않습니다.
- `content/` 밖에 있어서 사이트 빌드에는 포함되지 않습니다(`src/lib/server/content.ts`의 glob 대상이 `content/` 아래뿐이기 때문).
